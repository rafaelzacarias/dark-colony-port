## Ranked Minimal Follow-Ups

1. **Restore the predeployment reading sequence.** First edit: insert a cancellable briefing state in `startCampaign` before publishing `skirmish`; reuse `mission.briefing.rawText`, objectives and HCOM. Do not merely show the objectives overlay: the game would keep ticking underneath. Add the HUMAN OVERVIEW from HSTORY through the asset pipeline as the next adjacent step, followed by the briefing. Proposed small UI API: `showBriefing({rawText, objectives, signal, now}) -> Promise<deploy|cancel>`; reveal from elapsed time, first skip completes text, explicit deploy begins simulation/music, restored saves bypass introduction. Preserve existing loadingToken cancellation and gesture unlock. No synthetic narration or presumed H1 speech.
2. **Restore missing event sounds, starting with death only.** Extend `UnitAudioEvent`/`resolveUnitCue` with a DEA unit-type case. Dispatch once per committed death in `#presentCombatEvents`, using last known target position, camera listener and a bounded event watermark initialized on restore. Existing DEA 0 binding already supplies trooper clips. Keep audio out of speculative candidate updates. Add EXP only after locating an actual impact receipt and its source selector; never call an impact sound on weapon fire. A message cue can follow on newly committed `CampaignMessage.commandId`, but choosing MSG/H1 and exact timing needs source/reference confirmation. Do not schedule broad ambient loops by filename.
3. **Use existing voice alternatives without stacking responses.** Pass a deterministic per-session variant counter to `resolveUnitCue`; first test that repeated SEL/ACK calls use all mapped clips. Add a small response-channel owner holding `AudioVoice`/AbortController so rapid reselection cancels a pending stale reply and replaces the previous response without stopping GUN/music. Variant policy and any cooldown are explicit product choices, not claimed native timing. Transport loop ownership by carrier identity/phase is a later bounded extension, below these priorities.
